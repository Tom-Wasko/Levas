# Raporty

Wyniki zadań z `zadania/` (część A – analiza oczami gracza, część B – kalibracja). Każde zadanie zapisuje tu
swój raport, np. `analiza_gracza.md`, `kalibracja/inwentarz.md`, `kalibracja/stan_poczatkowy.md`,
`kalibracja/raport.md`. Propozycje zmian w notatkach autora trafiają do `…/notatki_do_zmiany.md`.
